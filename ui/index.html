About the data

Forza Horizon 6 launched on 19 May 2026 with more than 550 cars, and the roster keeps growing through Festival Playlist, Car Pass and Aftermarket additions. Nothing in this interface assumes a fixed car count — every list is driven by the current database version.

Where the data comes from

Cars live in a Supabase Postgres database, reached through the ForzaHelper API, and are never bundled into this frontend. Every table, filter option, count and comparison is the result of a live query, so the interface has no opinion about how many cars exist.

The Car Finder sends your words to the ForzaHelper API, which resolves them into structured filters and builds the query itself; the browser never writes SQL and holds no database credentials. The filters and the exact request are shown with every answer, so a wrong result can be traced to a wrong constraint rather than guessed at. Filter and sort state in the explorer produces the same kind of request, visible under “Show request”.

Units

Imperial and metric are separate columns in the database, not client-side conversions. The unit switch in the header changes which column is read for torque, weight and power-to-weight — in the table, in filters and sliders, and in sorting. Power is always in HP and value always in credits, so those never change. Weight and torque range filters reset when you switch, because their bounds belong to the other unit.
